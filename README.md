Sizzle & Serve — a rush-hour kitchen cooking game. Read the order board, click ingredients on the counter, grill the patty, build the dish on the plate, and ring the bell to serve it before the customer's patience runs out. Five recipes, combos, a 150-second shift, and a results screen with stars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: plain static files under `game/`.

## How to play

- Click an ingredient tray (or press keys 1–6) to add it to the plate. Patties go to the grill first — click the grill when one is ready.
- Build exactly what an order asks for, then ring the bell (or press Space) to serve.
- Serve fast for a perfect bonus; chain serves for a combo. An order that runs out of patience costs a heart — three hearts and the kitchen closes.
- `T` trashes the plate, `P` pauses, `M` mutes.
